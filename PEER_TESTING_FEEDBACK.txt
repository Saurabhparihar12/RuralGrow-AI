CLASSMATE 1 REVIEW: SENTINAUT (Live App: https://sentinaut.vercel.app)
--------------------------------------------------------------------------------

1. WHAT WORKS WELL:
   - The UI design and visual aesthetics are exceptionally sleek. The dark-mode glassmorphic dashboard with real-time sentiment distribution charts renders very smoothly. The sentiment classification engine responds quickly when pasting customer feedback snippets.

2. BUG / ISSUE FOUND:
   - Issue: CORS Block & Token Expiration Handling on Direct API Requests.
   - Steps to Reproduce:
     a. Navigate to https://sentinaut.vercel.app/login
     b. Register a new user account and log in.
     c. Open the browser developer console (F12) -> Network tab.
     d. Perform a search or post a new review.
     e. Observe that if the session sits idle for 10 minutes, subsequent API fetch calls return a CORS preflight warning / 401 Unauthorized status without redirecting the user back to the login page or prompting for re-authentication.
   - Constructive Suggestion: Add an interceptor to the frontend fetch/axios client that catches 401 response statuses and automatically clears expired localStorage tokens while redirecting to /login.

CLASSMATE 2 REVIEW: AGRIGROW AI (Live App: https://agri-grow.vercel.app)
--------------------------------------------------------------------------------

1. WHAT WORKS WELL:
   - The agricultural scheme recommendation wizard is very intuitive. Selecting a specific crop (e.g. Apples or Millets) immediately filters relevant state subsidies and Kisan Credit Card information with clear eligibility guidelines.

2. BUG / ISSUE FOUND:
   - Issue: Mobile Navigation Drawer Overflow on Small Viewports.
   - Steps to Reproduce:
     a. Open https://agri-grow.vercel.app on a mobile device or resize the desktop browser window below 400px width.
     b. Click the hamburger navigation menu icon.
     c. Observe that the navigation drawer menu items overlap with the background header action buttons, causing menu items to become unclickable on smaller screens.
   - Constructive Suggestion: Add `z-50` and `overflow-y-auto` CSS utility classes to the mobile drawer container to ensure it renders above all page elements.
