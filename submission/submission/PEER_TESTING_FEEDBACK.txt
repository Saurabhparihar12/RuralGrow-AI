2. BUG / ISSUE FOUND:
   - Issue: CORS Block & Token Expiration Handling on Direct API Requests.
   - Steps to Reproduce:
     a. Navigate to https://sentinaut.vercel.app/login
     b. Register a new user account and log in.
     c. Open the browser developer console (F12) -> Network tab.
     d. Perform a search or post a new review.
     e. Observe that if the session sits idle for 10 minutes, subsequent API fetch calls return a CORS preflight warning / 401 Unauthorized status without redirecting the user back to the login page or prompting for re-authentication.
   - Constructive Suggestion: Add an interceptor to the frontend fetch/axios client that catches 401 response statuses and automatically clears expired localStorage tokens while redirecting to /login.

   - Issue: Form Validation & Input Sanitization Error on Booking Inquiry Form.
   - Steps to Reproduce:
     a. Open https://sejoura-frontend.vercel.app in your browser.
     b. Click on any listed homestay card to view property details.
     c. Scroll down to the booking inquiry form.
     d. Enter special characters or unformatted text in the Full Name input field and click Submit.
